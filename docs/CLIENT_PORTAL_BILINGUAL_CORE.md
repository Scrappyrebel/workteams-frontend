# WorkTeams Client Portal: core English and Spanish support

The location-scoped bearer-link Client Portal now shows an English/Español selector with local preference persistence and browser-language fallback. This covers key navigation, visit and quality headings, agreement/contract labels, customer message actions, temporary-staffing requests, work status and client request history.

**Security model unchanged:** a revocable link authorizes one location only. It never grants full customer login, account-wide files, private staff details or new invoice access. Original notes, signatures and manager-written responses are displayed exactly as authored, not machine translated.

This is a protected customer-facing core bilingual batch; remaining contract explanations, manager screens and legal clauses still need human-reviewed Spanish localization.

Test the actual link with a Spanish-language phone and switch/reload behavior before classifying all bilingual functionality as field-certified.
